# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

- Add `DSProvider` (antd `ConfigProvider` wrapper) plus `dsSeedTokens`/`dsAiTokens`/`useDSMode`;
  seed tokens are guarded to stay identical to `tokens/design-tokens.json`.
- Convert Badge, Button, Card*, Input, and Skeleton into antd@6 facades: export names, class-name
  hooks, and accessibility contracts are unchanged; visuals now come from antd cssinjs. Dialog,
  DropdownMenu, and Tooltip remain Radix-based until consumers need them.
- BREAKING(facade): `Button` drops the unused `asChild` escape hatch (no consumer used it) and only
  passes through props consumers actually use.
- Add `npm run check:dist-tokens` to the gate: the built `dist/index.css` must expose every
  `--ui-*` variable from `src/styles/tokens.css`, preventing the `--ui-sidebar-wide` drift seen by
  `file:` consumers.
- Replace the warm-ivory Direction C palette with Ant Design aligned tokens v3 (antd@6
  default/dark algorithm values, light+dark) per ADR 0002. `tokens/design-tokens.json` is now the
  single token source; `src/styles/tokens.css` is generated by `npm run tokens:generate`
  (`scripts/generate-tokens-css.mjs` replaces the former CSS→JSON extractor).
- Add the `danger-strong` token for AA error text on soft backgrounds and map it in the Tailwind preset.
- Update the token contract tests for antd alpha-composited text colors and split WCAG AA pairs from
  documented 3.0:1 antd-parity exceptions.
- Establish the C “Warm Agent Workspace” semantic palette for light and dark themes.
- Add the Tailwind preset and eight accessible React primitives.
- Add shared application-shell, navigation, page-header, AI, and source-status patterns.
- Add a responsive Vite showcase for Digital Employees, Memory, and Docs.
- Add unit, accessibility, keyboard, build, and browser screenshot validation.
- Make screenshot baselines portable by bundling the showcase font and capturing a fixed viewport.
- Validate the published tarball from a clean TypeScript/React 18/Tailwind consumer.
- Document the design decision and Next.js RSC/Vite consumption boundaries.
- Build distributable files automatically during npm packaging and force public scoped-package access.
- Add npm repository metadata and stable public documentation links.
- Keep the clean tarball consumer executable inside an npm publish dry run.
- Ship ESM and CommonJS entry points so Next.js 14 and Tailwind 3 configuration loaders can consume the preset.
- Make the CommonJS Tailwind export return the preset directly and provide matching conditional types.
- Map the CommonJS React entry point to its generated `.d.cts` declarations.
